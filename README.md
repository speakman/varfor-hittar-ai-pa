# Varför hittar AI på saker?

En kort, animerad föreläsning (cirka 17 minuter) för nybörjare om hur chattbotar som ChatGPT fungerar och varför de ibland hittar på.

- **Presentationen:** https://speakman.github.io/varfor-hittar-ai-pa/ (gjord för stor skärm)
- **Fördjupning, källor och filmer:** https://speakman.github.io/varfor-hittar-ai-pa/fordjupning

## Visa presentationen
Öppna `docs/index.html` i en webbläsare. Den fungerar utan internet.

| Tangent | Gör |
|---|---|
| → ↓ mellanslag PageDown, klick | Nästa steg |
| ← ↑ PageUp | Föregående steg |
| S | Talarvy med manus, nästa klick och klocka |
| F | Helskärm |
| B | Svart skärm |
| T | Ljust/mörkt tema |
| H | Alla tangenter |

## Innehåll
- `docs/` – sajten (GitHub Pages serverar denna katalog)
- `content/innehall.md` – manus, källor och förenklingar

Typsnitt: Source Serif 4 och Atkinson Hyperlegible Next, båda under SIL Open Font License 1.1 (licensfiler i `docs/assets/fonts/`).
